# Endless Survivor
Portrait mobile survivor game (HTML canvas wrapped with Capacitor).

## Build the Android APK
1. Push this folder to a GitHub repo (branch `main`).
2. Open the **Actions** tab, run **Build Android APK** (it also runs on every push).
3. Download the `endless-survivor-apk` artifact, unzip it and install `app-debug.apk` on your phone.

Edit the game in `www/index.html`. Game balance lives in the `C` config at the top of its script.
